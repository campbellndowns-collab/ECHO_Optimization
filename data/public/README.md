# Public / redistributable bootstrap data

This directory is reserved for a **sanitized, redistributable** component subset
suitable for a public GitHub repository and portfolio demo.

Nothing is published here yet.

Until a licensing/provenance audit completes:

- do not copy the full `component_warehouse.sqlite` here
- do not copy APC aerodynamic coefficient tables here without confirmed rights
- do not copy vendor price scrapes or unclear-license cell catalogs here

Development and production engineering runs should use `data/private/` (or the
equivalent local PyThrust install paths).
